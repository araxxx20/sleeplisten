# Assets Folder

This folder contains images for the World Time app.

## Required Images:

1. **day.png** - An image representing daytime (sun, bright sky, etc.)
2. **night.png** - An image representing nighttime (moon, stars, dark sky, etc.)

## Image Requirements:
- Recommended size: 200x200 pixels or larger
- Format: PNG or JPG
- Place the images directly in this folder

## Fallback:
If images are not found, the app will show colored circles with sun/moon icons as a fallback.

## Example Images:
You can use any free stock photos or create simple images:
- Day: Bright sky with sun, daytime landscape
- Night: Dark sky with moon and stars, nighttime cityscape
